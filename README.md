# Chicago Open Bioinformatics

Chicago Open Bioinformatics is a Chicago-based open-science community focused on developing,
sharing, and sustaining accessible bioinformatics projects in the open. The group brings
together researchers, software developers, community laboratory practitioners, educators, and
other contributors who want to collaborate on practical tools, reproducible workflows, and
community-centered scientific infrastructure.

This repository hosts the public GitHub Pages site for the Chicago Open Bioinformatics project
showcase. The site highlights community repositories, makes it easier to discover active work,
and provides a clear entry point for people interested in participating in local and open-source
bioinformatics efforts.

## Who this repository is for

This repository is intended for:

- contributors maintaining or improving the Chicago Open Bioinformatics website
- collaborators looking for active community projects and reusable resources
- researchers and practitioners interested in open, community-driven bioinformatics work
- organizers and partners who want a clear overview of the group's public project presence

## Related community references

Chicago Open Bioinformatics is part of the broader [ChiTownBio](https://chitownbio.org/)
community and aligns with the open-science mission of the
[Open Bioinformatics Foundation](https://www.open-bio.org/). These organizations provide
additional opportunities to connect with events, collaborators, and open bioinformatics
initiatives beyond this repository.

## Repository contents

This repository contains the source for the GitHub Pages site, including:

- `index.html` for site content and structure
- `styles.css` for site styling
- `search.js` for client-side project filtering
